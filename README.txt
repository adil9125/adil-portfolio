# Adil Anwar — Personal Portfolio

A modern, responsive, and professionally designed personal portfolio website showcasing my background, technical expertise, projects, and professional journey.

## 🚀 Getting Started

This portfolio is built as a lightweight, single-page website using a standalone `index.html` file.

### Running Locally

1. Download or clone this repository.
2. Locate the `index.html` file.
3. Open it in any modern web browser.
4. The website will launch instantly without requiring additional installation or configuration.

### 🌐 External Dependencies

The website uses Google Fonts to enhance its typography and visual presentation. An active internet connection is recommended to load the selected fonts. System fonts will be used as a fallback when offline.

## ☁️ Deployment

This website can be deployed using any static website hosting platform, including:

* **GitHub Pages**
* **Netlify**
* **Vercel**

Simply upload the `index.html` file and configure your preferred hosting provider.

## 🛠️ Customization

All website content, styling, and functionality are contained within `index.html`.

To personalize the portfolio:

1. Open `index.html` using a code editor such as Visual Studio Code.
2. Modify the text, images, and personal information.
3. Customize the styling and layout according to your preferences.
4. Save your changes and refresh the browser to preview them.
