Adil Anwar Portfolio
====================
Ek single-file website hai: index.html.

Kholne ke liye: index.html par double-click karo (kisi bhi browser me khulega).
Fonts Google Fonts se aate hain, isliye internet chahiye; bina internet ke system fonts use honge.

Host karne ke liye: index.html ko GitHub Pages, Netlify ya Vercel par upload kar do.
Content badalne ke liye index.html ko kisi text editor me kholo.
